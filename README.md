# Customer Retention and Churn Analysis Dashboard

## Project Overview
This project analyzes customer retention and churn behavior using the Telco Customer Churn dataset. The dashboard was developed in Power BI to identify customer retention patterns, contract preferences, service usage trends, and customer lifetime insights.

## Tools Used
- Power BI
- Microsoft Excel
- GitHub

## Dataset
Telco Customer Churn Dataset

## Dashboard Pages

### Page 1: Customer Churn Analysis
- Churn by Contract Type
- Churn by Internet Service
- Churn by Payment Method
- Overall Churn Rate KPI

### Page 2: Customer Retention Analysis
- Retained Customers by Contract Type
- Retained Customers by Internet Service
- Retained Customers by Gender
- Total Retained Customers KPI

### Page 3: Customer Lifetime Trends
- Customer Tenure Distribution
- Average Monthly Charges by Tenure
- Average Total Charges by Contract Type
- Average Customer Tenure KPI

## Key Insights
- Retention Rate: 73.4%
- Month-to-Month contracts have the highest number of retained customers.
- DSL customers show stronger retention compared to customers without internet service.
- Average customer tenure is 32.37 months.
- Customers with longer tenure contribute significantly to overall revenue.
